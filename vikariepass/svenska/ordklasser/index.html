Träna ordklasser

Vikariepass i svenska · Åk 7–9

Så känner du igen sex ordklasser

Ordklassen beror ibland på hur ordet används. Läs hela meningen när du avgör vilken ordklass ett ord tillhör.

Substantiv

Namn på saker, personer, platser och begrepp.

hund, boll, Lisa, glädje

Knep Många substantiv kan ha en, ett eller flera framför sig. Egennamn som Lisa och Löberöd är också substantiv.

Verb

Talar om vad någon gör, vad som händer eller hur något förhåller sig.

springer, sover, är, tänkte

Knep Prova att sätta att framför verbets grundform, som i att springa, eller böj det i tid, som i springer – sprang.

Adjektiv

Beskriver ett substantiv eller pronomen.

stor, glad, röd, rolig

Knep Pröva en glad elev, ett glatt barn, flera glada barn. Många adjektiv kan jämföras, som i rolig, roligare, roligast.

Pronomen

Står i stället för ett namn eller substantiv, pekar ut någon eller något, eller visar vem något tillhör.

jag, hon, den, min, någon

Knep I Lisa läser kan du byta ut Lisa mot hon. I min bok visar min vem boken tillhör.

Räkneord

Anger antal eller ordning.

tre, hundra, första, sjunde

Knep Fråga hur många? eller vilken i ordningen?

Adverb

Berättar ofta hur, var, när eller hur ofta något händer. Adverb kan också ändra betydelsen av ett annat ord eller hela meningen.

snabbt, hemma, igår, inte

Knep Fråga till exempel hur springer hon? Svaret snabbt beskriver springer. Ordet inte talar om att något förnekas.

Adjektiv eller adverb?

Ett snabbt tåg. Adjektiv eftersom ordet beskriver tåget.

Tåget kör snabbt. Adverb eftersom ordet beskriver hur tåget kör.
